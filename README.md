# 시간표 앱 설치하기

폰 홈 화면에 아이콘으로 깔아서 쓰는 방식입니다. 앱스토어 등록이나 개발자 계정 없이,
파일 몇 개만 인터넷에 올려두면 됩니다. 비용은 들지 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 시간표 본체 |
| `manifest.webmanifest` | 앱 이름·아이콘 정보 |
| `sw.js` | 오프라인에서도 열리게 해주는 스크립트 |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | 홈 화면 아이콘 |

**7개 파일을 같은 폴더에 함께 두세요.** 하나라도 빠지면 아이콘이나 오프라인 기능이 안 됩니다.

## 1단계 — 인터넷에 올리기

주소(https)가 있어야 홈 화면 앱으로 설치됩니다. 둘 중 편한 쪽을 고르세요.

**GitHub Pages**
1. github.com에서 저장소를 새로 만듭니다. 공개(Public)로 두세요.
2. 파일 7개를 모두 업로드합니다.
3. 저장소의 Settings → Pages → Source를 `main` 브랜치, 폴더는 `/ (root)`로 지정하고 저장합니다.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다.

**Netlify**
1. app.netlify.com에 가입하고 Sites 화면에 폴더째로 끌어다 놓습니다.
2. 바로 주소가 나옵니다.

공개 저장소라 시간표 내용이 남에게 보이지 않을까 걱정된다면 — 걱정 안 하셔도 됩니다.
입력한 수업 정보는 서버가 아니라 폰 안에만 저장돼서, 올라가는 건 빈 시간표뿐입니다.

## 2단계 — 홈 화면에 추가

**아이폰 (사파리로 열어야 합니다. 크롬은 안 됩니다)**
1. 만들어진 주소를 사파리에서 엽니다.
2. 아래 공유 버튼 → 「홈 화면에 추가」 → 추가.

**안드로이드 (크롬)**
1. 주소를 크롬에서 엽니다.
2. 「앱 설치」 안내가 뜨면 누르고, 안 뜨면 우측 상단 ⋮ → 「홈 화면에 추가」.

이제 아이콘을 누르면 주소창 없이 전체화면으로 열리고, 지하철처럼 인터넷이 끊기는 곳에서도 켜집니다.

## 알아두면 좋은 것

- **저장 위치**: 일정은 그 브라우저 안에만 저장됩니다. 다른 기기와 자동으로 동기화되지 않습니다.
- **백업**: 하단의 「백업 저장」을 누르면 JSON 파일이 하나 떨어집니다. 새 폰으로 옮기거나
  브라우저 데이터를 지우기 전에 받아두고, 「백업 불러오기」로 되돌리면 됩니다.
- **주의**: 사파리·크롬에서 「인터넷 사용 기록 및 데이터 지우기」를 하면 시간표도 함께 지워집니다.
  학기 초에 한 번 백업해 두는 걸 권합니다.
- **수정**: 내용을 고치고 싶으면 `sw.js` 첫 줄의 `timetable-v1`을 `timetable-v2`처럼 바꿔서
  다시 올리세요. 그래야 폰이 옛날 화면을 계속 보여주지 않습니다.
